# `#03` Laravel: Pierwsze kroki (1-9)

Utwórz dynamiczną ścieżkę, z której będzie odczytywana miejscowość np. `/weather/{place}`.

Na początek wyświetl na stronie samą nazwę miejscowości. Pamiętaj, że dane wprowadzone przez użytkownika muszą być bezpiecznie wyświetlane w widoku.

**Zadanie dodatkowe:** wykonaj [pobieranie danych](https://laravel.com/docs/12.x/http-client) o pogodzie za pomocą [odpowiedniego API](https://weatherstack.com/). Zastanów się jaki ewentualny problem może nieść za sobą pobieranie tych danych na backendzie.
